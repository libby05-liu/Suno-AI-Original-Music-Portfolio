# Suno AI Original Music Portfolio

A small generative-AI music portfolio created as part of an original
idol-group content project. The project explored how AI-assisted music
generation can support early-stage creative development while keeping
concept definition, evaluation, selection, and final creative judgement
human-led.

## Project Background

The goal was to develop original music that matched the intended
identity, atmosphere, and content direction of an idol-group project,
alongside related promotional content.

Suno AI was used as a creative production tool to rapidly explore
alternative musical directions. Rather than treating the first generated
result as a finished product, the workflow focused on iterative
prompting, comparison, selection, and refinement.

## Human--AI Collaboration

**My role** - Defined the song concept, intended mood, creative
direction, and desired audience impression - Translated creative ideas
into prompts describing style, atmosphere, pacing, and other musical
characteristics - Compared multiple generated alternatives and
identified outputs that best matched the intended direction - Used human
judgement to evaluate consistency, emotional expression, and suitability
for the wider project - Participated in the broader original-song and
promotional-content workflow

**Suno AI's role** - Generated alternative musical interpretations from
creative prompts - Enabled rapid experimentation with different styles,
moods, and arrangements - Supported iterative exploration during the
early creative-development process

## Core Challenge

A key challenge was the variability of generative music outputs. Initial
generations did not always match the intended style or emotional tone. I
therefore refined prompts, separated broad creative ideas into more
specific musical requirements, generated multiple alternatives, and
compared outputs before selecting the most suitable direction.

This process developed a practical workflow of:

**Creative brief → Prompt design → AI generation → Human evaluation →
Prompt iteration → Selection**
